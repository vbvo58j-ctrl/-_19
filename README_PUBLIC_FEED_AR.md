# المنشورات العامة القريبة في بلوساب

- تمت إضافة أيقونة «المنشورات» بجوار شريط القصص في الواجهة الرئيسية.
- صفحة المنشورات تدعم إنشاء منشور نصي أو صورة أو فيديو، وإضافة هاشتاجات، والإعجاب والتعليقات وحذف منشورك والإبلاغ محليًا.
- تُضغط الصور عند اختيارها والفيديوهات عبر VideoCompress قبل حفظها.
- تُحفظ المنشورات محليًا بصورة دائمة. عند تشغيل خدمة الشبكة المحلية، يحاول التطبيق إرسال المنشورات إلى الأجهزة المكتشفة على شبكة Wi-Fi/LAN نفسها. يتم نقل الوسائط داخل رسالة JSON مضمنة كـ Base64 فقط عندما يكون حجم الملف أقل من نحو 900 KiB لتجنب إغراق الشبكة؛ الملفات الأكبر تبقى محلية ولا تصل كاملة إلى الأجهزة الأخرى.
- يوجد تدفق طلب صداقة: الضغط على المحادثة يرسل طلبًا عبر LAN، ويظهر للمستلم طلب قبول/رفض؛ عند القبول يحاول الطرفان فتح ChatScreen باستخدام عنوان LAN المكتشف.

## حدود مهمة

هذه مزامنة محلية أولية وليست خدمة عامة عبر الإنترنت أو خادمًا دائمًا. لا تنتقل المنشورات تلقائيًا بين شبكات Wi-Fi مختلفة، وقد لا يصل طلب الصداقة إذا لم يكن الطرف الآخر متصلًا ومشغّلًا للشبكة المحلية. الإعجابات والتعليقات الحالية محفوظة محليًا ولا تتم مزامنتها بعد التفاعل. لا يوجد حتى الآن نظام مركزي للتحقق من الهوية أو الحظر أو حل تعارضات المنشورات. لم يتم بناء APK أو تشغيل `flutter analyze` في بيئة التعديل لعدم توفر Flutter SDK.
